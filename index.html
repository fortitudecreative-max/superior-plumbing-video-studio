Step 2 of 3 — Connect Google Drive

Connect your shared Google Drive folder so the studio can pull raw footage automatically. You'll need a Google Cloud API key and OAuth Client ID.

How to get these credentials (takes ~5 min)
1. Go to console.cloud.google.com
2. Create a new project (e.g., "Superior Video Studio")
3. Enable the Google Drive API and Google Picker API
4. Go to Credentials → Create OAuth Client ID (Web application type)
5. Add your domain to Authorized JavaScript Origins
6. Copy the Client ID and API Key here
7. For Folder ID: open the shared folder in Drive and copy the ID from the URL

Step 3 of 3 — AI Engine Setup

Choose your AI engine for analyzing footage. The AI will transcribe audio, identify content type, detect key moments, and recommend which template to use.

What the AI analyzes in each clip:
🎙️ Audio Transcription — what's being said (for captions + hook detection)
📊 Content Classification — which pillar it fits (Day in Life, Tips, B&A, etc.)
⚡ Key Moment Detection — the most engaging 3-5 seconds for the hook
😱 Reaction & Emotion — finds gross reveals, satisfying moments, funny reactions
🎯 Template Matching — recommends which template + segment to use
✂️ Smart Trim Points — suggests optimal in/out points per segment
